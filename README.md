# Waltive Knowledge Base

Static, GitHub Pages-ready knowledge site for China and India building-materials sourcing, tariffs and commercial enablement.

## Publish

1. Push these files to the `main` branch of `ahmed90-techlab/waltive-knowledge-base`.
2. In GitHub repository **Settings → Pages**, set the source to **GitHub Actions**.
3. Add `knowledge.waltive.com` as the custom domain in Pages settings.
4. At the DNS provider, point the `knowledge` CNAME record to `ahmed90-techlab.github.io`.
5. Once GitHub validates DNS, enable HTTPS.

## Notes

- The site is dependency-free and client-side search loads `data/search-index.json`.
- Review all commercial, tariff and customs content before publication; it is not legal or customs advice.
- Canonical URLs, `robots.txt`, `sitemap.xml`, `404.html`, CNAME and Pages workflow are included.
